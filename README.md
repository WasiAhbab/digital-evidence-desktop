# TraceLock — Digital Evidence Management System

TraceLock is a Windows desktop application designed to help manage digital evidence and forensic investigation cases in an organized and secure way. The system brings together case management, evidence handling, chain of custody tracking, forensic analysis, integrity verification, audit history, notifications, reports, and user management in one application.

The project was developed using C#, .NET 8, Windows Forms, Entity Framework Core, and Microsoft SQL Server. It focuses on demonstrating the practical use of Object-Oriented Programming and modern .NET technologies in a real-world digital forensics scenario.

---

## Features

- Case management
- Digital evidence management
- Evidence file storage and retrieval
- Chain of custody tracking
- Forensic analysis records
- Evidence integrity verification
- Audit history and activity tracking
- User and role management
- Notifications
- Report generation
- Secure local data storage
